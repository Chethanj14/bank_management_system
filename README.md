# Bank Management System

A full-stack Bank Management System built using Django REST Framework and React.

## Features

- Customer Management
- Account Management
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Dashboard Analytics
- Transaction Charts
- CSV Export
- JWT Authentication
- Login & Logout
- Protected Routes

## Tech Stack

### Backend
- Django
- Django REST Framework
- SQLite

### Frontend
- React
- Vite
- Bootstrap
- Axios
- Recharts
