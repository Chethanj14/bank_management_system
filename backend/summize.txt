9. Implemented Deposit API

Endpoint:

POST /api/deposit/

Input:

{
    "account_number":"123456789",
    "amount":5000
}

Logic:

Find Account
Add amount to balance
Save Account
Create Transaction record
Return new balance

Response:

{
    "message":"Deposit Successful",
    "new_balance":"30000.00"
}
10. Implemented Withdraw API

Endpoint:

POST /api/withdraw/

Input:

{
    "account_number":"123456789",
    "amount":5000
}

Logic:

Check account balance
If sufficient:
    Deduct amount
    Save account
    Create transaction
Else:
    Return error

Response:

{
    "message":"Withdraw Successful",
    "new_balance":"25000.00"
}
11. Implemented Transfer API

Endpoint:

POST /api/transfer/

Input:

{
    "from_account":"123456789",
    "to_account":"987654321",
    "amount":1000
}

Logic:

Check sender balance
Deduct from sender
Add to receiver
Save both accounts
Create transfer transaction records

Response:

{
    "message":"Transfer Successful"
}
